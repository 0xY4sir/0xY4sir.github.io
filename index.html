ML-Powered Intrusion Detection System

Built and optimized a 6-class Intrusion Detection System (IDS) to classify network traffic into Normal, Blackhole, TCP-SYN, PortScan, Diversion, and Overflow using a 4,998-record dataset.

Started with a weak MLP baseline that achieved only 19% attack detection. Upgraded to 6 algorithms (Gradient Boosting, Random Forest, SVM, Decision Tree, KNN, MLP) + a Soft-Voting Ensemble that delivered 98% accuracy, 86% attack detection rate, and 1% false alarm rate.

86% Attack Detection Rate
1% False Alarms
